# ClaryJur — Demonstração pública estática v5.8

Esta é uma vitrine independente, sem backend, sem autenticação, sem armazenamento e sem dados pessoais reais. Não representa homologação do aplicativo completo.

## Publicação gratuita sugerida
Crie um repositório GitHub contendo `index.html` e habilite GitHub Pages em Settings > Pages > Deploy from a branch > main / root. Verifique o URL emitido pelo GitHub. Não envie o código do servidor privado nem arquivos de banco de dados para esse repositório.

## Testes
1. Abrir `index.html` em navegador e conferir layout.
2. Clicar em `Simular atendimento` e verificar alteração da mensagem.
3. Confirmar ausência de chamadas de rede externas no arquivo.

## Pendências
Publicação efetiva e URL; validação visual em celulares reais; integração com o sistema completo; autenticação e revisão de segurança do backend; LGPD, backups e homologação.
